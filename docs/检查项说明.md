# 检查项说明

| ID | 检查 | 级别 | owner/fix | 判定 | 修复（见 `vhm plan`） |
|---|---|---|---|---|---|
| P-01 | 面板端口公网监听 | P0 | 1panel/guided | `ss` 中面板端口绑定 0.0.0.0/:: | 改端口 + 防火墙仅放行管理 IP |
| P-02 | 安全入口 | P1 | 1panel/guided | `1pctl user-info` 无入口 | 设置 → 安全 |
| P-03 | MFA | P1 | 1panel/guided | 无法自动读取，恒为 unknown | 开启两步验证 |
| P-04 | 1Panel 版本 | P1 | 1panel/guided | 仅报告当前版本 | 检查更新 |
| E-01 | 容器端口绑定 | P0 | 1panel/guided | HostIp 为空/0.0.0.0 | 取消端口外部访问 |
| E-02 | DOMAIN https | P0 | 1panel/guided | config.json/env 中 DOMAIN 非 https | 站点启用 HTTPS |
| E-03 | /admin 公网可达 | P0 | 1panel/guided | `EXTERNAL_PROBE_URL` 响应体只含 3 位状态码：2xx/3xx=fail，4xx=pass，其余/失败=unknown | OpenResty IP 白名单 |
| A-01 | 开放注册 | P0 | 1panel/guided | signups_allowed≠false（默认 true） | 关闭注册 |
| A-02 | 免令牌 admin | P0 | 1panel/guided | disable_admin_token=true | 移除 |
| A-03 | ADMIN_TOKEN | P1 | 1panel/guided | 非 argon2 即 fail（只记长度） | `vaultwarden hash` |
| A-04 | 功能面 | P2 | 1panel/guided | 密码提示/Send/紧急访问/组织创建 | 按需关闭 |
| A-05 | 图标服务 | P2 | 1panel/guided | icon_service≠internal | internal |
| C-01 | 容器特权 | P0 | 1panel/report | privileged/cap_add/docker.sock | 编辑 compose |
| C-02 | 镜像固定 | P1 | 1panel/guided | latest 或无 tag | 固定版本 |
| S-01 | 版本落后 | P1 | 1panel/guided | `/api/config` 对比上游 release；无网络 unknown | 先 vbm 备份再升级 |
| N-01 | SSH | P1 | host/guided | `sshd -T` 密码或 root 登录为 yes | drop-in 配置 |
| N-02 | 防火墙 | P1 | host/guided | ufw/firewalld/nftables 均未启用 | 启用 |
| N-03 | 自动安全更新 | P2 | host/guided | 未启用 unattended-upgrades/dnf-automatic | 启用 |
| D-01 | 备份 | P0 | vhm/report | 未装 vbm、`vbm status` 非 0 退出、报告超期或非零失败计数（`failed: 0` 不算） | 安装 vbm |
| D-02 | 数据目录权限 | P1 | host/**auto** | 数据目录、`db.sqlite3`(+`-wal`/`-shm`)、`rsa_key*`、`config.json`、`attachments/`、`sends/` 其他用户有任意权限 | `chmod o-rwx` |
| D-03 | 磁盘加密 | P2 | host/report | 非 LUKS | 迁移 |

**注意**：Vaultwarden 在 /admin 保存的设置写入 `config.json`，优先于环境变量，因此审计按 config.json → env → 默认值取有效值。
