# 快速开始

1. 以 root 把仓库克隆到 `/opt`（root 所有、755），运行安装：
   ```bash
   sudo git clone https://github.com/OmenTwwnmfm/vaultwarden-hardening-manager /opt/vaultwarden-hardening-manager
   sudo bash /opt/vaultwarden-hardening-manager/run.sh
   ```
2. `[01]` 首次配置：检查依赖、识别 Vaultwarden 实例（已装 vbm 时复用其实例），清理 0.1.x 的定时巡检。
3. `[02]` 安全体检：看哪些项是「危险」「注意」。
4. 推荐的加固顺序：
   - `[04]` 确认 root 的登录密钥都是你自己的；
   - `[15]` 配置防火墙规则，`[16]` 启用 Fail2Ban；
   - `[06]` 选择 SSH 登录方式（密码 / 密钥 / 密码 + TOTP / 密钥 + TOTP）；
   - `[19]` 关闭开放注册，`[20]` 不用时关闭后台，`[22]` 一键推荐安全选项；
   - `[23]` 自动安全更新，`[24]` 内核网络参数；
   - `[09]` 查看 1Panel 面板状态：面板端口对所有 IP 开放时，在 1Panel 防火墙中只放行你的 IP；必要时在 `[10]` 修改默认端口；
   - 体检提示 Docker 端口暴露时，在 1Panel 应用参数中取消「端口外部访问」。

出问题时运行 `[26]` 脱敏诊断，把输出贴进 Issue。
