# 快速开始

1. 以 root 把仓库克隆到 `/opt`（root 所有、755），运行安装：
   ```bash
   sudo git clone https://github.com/OmenTwwnmfm/vaultwarden-1panel-hardening-manager /opt/vaultwarden-1panel-hardening-manager
   sudo bash /opt/vaultwarden-1panel-hardening-manager/run.sh
   ```
2. `[01]` 首次配置：检查依赖、识别 Vaultwarden 实例（已装 vbm 时复用其实例），清理 0.1.x 的定时巡检。
3. `[02]` 安全体检：看哪些项是「危险」「注意」。
4. 推荐的加固顺序：
   - `[04]` 确认 root 的登录密钥都是你自己的；
   - `[11]` 启用 Fail2Ban；
   - `[06]` 启用 SSH 2FA（密钥 + 动态口令），按提示另开窗口测试登录后再确认；
   - `[14]` 关闭开放注册，`[15]` 不用时关闭后台，`[17]` 一键推荐安全选项；
   - `[18]` 自动安全更新，`[19]` 内核网络参数；
   - `[10]` 如果提示 Docker 端口暴露，在 1Panel 应用参数中取消「端口外部访问」。

出问题时运行 `[21]` 脱敏诊断，把输出贴进 Issue。
