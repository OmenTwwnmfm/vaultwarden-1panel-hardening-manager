# 快速开始

1. 以 root 将仓库克隆到 `/opt`（root 所有、755）：
   ```bash
   sudo git clone https://github.com/OmenTwwnmfm/vaultwarden-1panel-hardening-manager /opt/vaultwarden-1panel-hardening-manager
   sudo bash /opt/vaultwarden-1panel-hardening-manager/run.sh
   ```
2. `[01]` 首次配置：生成 `/etc/vaultwarden-hardening.conf` 并识别实例（已装 vbm 时复用其实例）。
3. 编辑配置，填写 `VW_DOMAIN`，可选 `EXTERNAL_PROBE_URL` 与通知。
4. `[03]` 全量审计 → `[05]` 查看报告。
5. `[07]` 生成计划：1Panel 条目按指引在面板中手动修改；`[09]` 仅执行可自动项。
6. `[16]` 安装定时巡检，出现新的失败项时通知。

出问题时运行 `[21]` 脱敏诊断，把输出贴进 Issue。
